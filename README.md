### Hey! I'm DoronZ 👋

I'm very passionate for developing research & automation tools. Currently mainly focused on iOS research.

### Projects

| Project | Description
| ------- | ------------
| [pymobiledevice3](https://github.com/doronz88/pymobiledevice3) | Pure python3 implementation for working with iDevices (iPhone, etc...).
| [harlogger](https://github.com/doronz88/harlogger) | Simple utility for sniffing decrypted HTTP/HTTPS traffic on a macOS/iOS device (either jailbroken or not)
| [Hilda](https://github.com/doronz88/hilda) | LLDB wrapped and empowered by iPython's features
| [swift_reversing](https://github.com/doronz88/swift_reversing) | My ongoing primer on reversing Swift
| [fa](https://github.com/doronz88/fa) | Automation tool for locating symbols & structs in binary (primary IDA focused)
| [rpc-project](https://github.com/doronz88/rpc-project) | Minimalistic server (written in C) and a python3 client to allow calling native functions on a remote host for automation purposes
| [ipsw_parser](https://github.com/doronz88/ipsw_parser) | Parse and extract .ipsw files
| [pycrashreport](https://github.com/doronz88/pycrashreport) | Python3 parser for Apple's crash reports
| [cfprefsmon](https://github.com/doronz88/cfprefsmon) | Python utility for discovering interesting CFPreferences values on iDevices
| [applecatalog](https://github.com/doronz88/applecatalog) | Python library and CLI for listing and downloading Apple's updates for macOS (Security updates, CommandLineTools, OS Upgrades and etc...)
| [c-helpers](https://github.com/doronz88/c-helpers) | Helpers for c-structs sizes and offsets
| [bytestruct](https://github.com/doronz88/bytestruct) | Typed, dependency-free binary records and codecs on top of struct
| [ansilogs](https://github.com/doronz88/ansilogs) | Colored, single-line log output for command-line tools: a dependency-free coloredlogs.install() replacement

Older projects: [cklogger](https://github.com/doronz88/cklogger) (sniffing CloudKit usages on iDevices), [simpleelf](https://github.com/doronz88/simpleelf) (parse and build simple ELFs), [pytbd](https://github.com/doronz88/pytbd) (Apple's .tbd file manipulation).
